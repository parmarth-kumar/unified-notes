Algorithm Visual Cues & Reference

Quick visual reference for the algorithms visualized above. For rigorous proofs, formal loop invariants, and complete C++ implementations, consult the linked Markdown notes.

Bubble Sort
O(N²) Stable

Visual Cue: Adjacent pairs slide and swap if out of order. After each pass, the largest remaining element sinks to the right end (✓ Sunk). Adaptive early exit halts if no swaps occur.

Selection Sort
O(N²) Unstable

Visual Cue: Scans the unsorted suffix to locate the minimum element (⭐ Min), then executes at most one swap into the target slot (🎯 Target), minimizing memory writes.

📖 Study Selection Sort in theory.md →
Insertion Sort
O(N²) / O(N) Stable

Visual Cue: Lifts the active element (🃏 Key) above the array, shifts larger sorted cards to the right (➡️ Shift), and drops the key into its sorted slot. Highly adaptive on nearly-sorted data.

📖 Study Insertion Sort in theory.md →
Counting Sort
O(N + K) Non-Comparison

Visual Cue: Phase 1 scans range and tallies element counts in the live frequency map using an offset (supporting negative integers). Phase 2 reconstructs the array sequentially in linear time.
